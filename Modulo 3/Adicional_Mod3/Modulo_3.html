Módulo 3: Estructuras No Lineales

Árboles y Grafos en C++ (Enfoque POO)

1. Árboles y Árboles Binarios

Teoría: Las estructuras jerárquicas se modelan con árboles, utilizando nodos conectados por relaciones padre-hijo. Un Árbol Binario restringe esto a dos ramificaciones máximas (izquierda y derecha).

Raíz
Izq
Der

Ejemplo en código:

class NodoArbol {
public:
    std::string area_pad;
    NodoArbol* izquierdo;
    NodoArbol* derecho;
    NodoArbol(std::string area) : area_pad(area), izquierdo(nullptr), derecho(nullptr) {}
};
🍰 De la vida cotidiana: Un árbol genealógico. Tus abuelos son la raíz, tus padres los nodos intermedios, y tú eres el nodo hoja (el final de la rama).

2. Árbol Binario de Búsqueda (ABB)

Teoría: Es una estructura donde los valores menores van a la rama izquierda y los mayores a la derecha. Esto optimiza la búsqueda al descartar mitades enteras de datos en cada paso.

Buscando: 30
50
30
70
< 50 (Va a Izq)
> 50

Ejemplo en código (Incidente Crítico):

NodoABB* insertar(NodoABB* raiz, int folio) {
    if (raiz == nullptr) return new NodoABB(folio);
    if (folio < raiz->folio_turno) 
        raiz->izq = insertar(raiz->izq, folio); // Menores a Izquierda
    else if (folio > raiz->folio_turno) 
        raiz->der = insertar(raiz->der, folio); // Mayores a Derecha
    return raiz;
}
🍰 De la vida cotidiana: Un archivero alfabético. Si buscas el expediente de "Hana chan" en el cajón de la "M", sabes inmediatamente que debes buscar hacia la izquierda, ignorando el lado derecho.

3. Grafos (Redes e Interconexiones)

Teoría: Modelan relaciones complejas sin jerarquía estricta. Están compuestos por nodos y aristas (conexiones). Si la conexión es bidireccional es No Dirigido; si tiene un solo sentido, es Dirigido.

PC-1
PC-2
Serv

Ejemplo en código (Incidente Crítico):

class RedComputadoras {
public:
    std::vector<std::string> equipos = {"PC-1", "PC-2", "Servidor"};
    // Matriz de adyacencia (Conexiones bidireccionales PAD-Bienestar)
    int conexiones[3][3] = {
        {0, 1, 1}, // PC-1 conectada a PC-2 y Servidor
        {1, 0, 1}, // PC-2 conectada a PC-1 y Servidor
        {1, 1, 0}  // Servidor conectado a PC-1 y PC-2
    };
};
🍰 De la vida cotidiana: El mapa del metro es un grafo no dirigido (vas y vienes por la misma vía). Seguir a alguien en Twitter es un grafo dirigido (tú puedes seguir a alguien sin que te sigan de vuelta).

4. Representación: Lista de Adyacencia

Teoría: En lugar de una matriz llena de ceros (que gasta RAM), la Lista de Adyacencia usa vectores dinámicos en C++ para guardar únicamente las conexiones que sí existen, optimizando la memoria.

PC-1
PC-2
Servidor
PC-2
PC-1

Ejemplo en código:

class GrafoOptimizado {
private:
    std::vector<std::vector<int>> listaAdyacencia; 
public:
    void conectarEquipos(int origen, int destino) {
        listaAdyacencia[origen].push_back(destino);
        listaAdyacencia[destino].push_back(origen); // Bidireccional
    }
};
🍰 De la vida cotidiana: La Matriz de Adyacencia es como una tabla gigante de Excel con todos los habitantes de la ciudad (desperdiciando espacio). La Lista de Adyacencia es tu celular: solo anotas a quienes realmente conoces.
