Estructuras de Datos: Módulo 1

Fundamentos, Arreglos y Persistencia en C++

1. Estructuras de Datos vs. Tipos de Datos

Teoría (C++ según Deitel): Los tipos de datos básicos describen un valor individual. En contraste, una estructura de datos organiza, manipula y almacena datos en memoria para usarlos eficientemente. En C++ esto evoluciona hacia Tipos de Datos Abstractos (TDA) usando clases y objetos.

Ejemplo en código (Incidente Crítico):

#include <iostream>
#include <vector>
#include <string>

int main() {
    // Tipo de dato primitivo
    int id_usuario = 101; 

    // Estructura de datos (Vector dinámico)
    std::vector<std::string> sesiones_activas;
    sesiones_activas.push_back("Usuario 101 - Equipo 1"); 
    return 0;
}

Explicación: id_usuario es un dato primitivo simple int. sesiones_activas es un std::vector que agrupa múltiples cadenas de texto, organizando las sesiones del PAD-Bienestar.

🍰 De la vida cotidiana: Preparar un pastel. Los tipos de datos son los ingredientes sueltos en tu mesa. La estructura de datos es la receta maestra terminada y organizada.

2. Arreglos (Las bases estáticas)

Teoría (C++ según Deitel): Almacenan múltiples valores de manera secuencial y contigua. Su principal limitación es que su tamaño es rígido. En C++, el contenedor std::array encapsula el arreglo estático para evitar desbordamientos, pero mantiene esta naturaleza inmutable.

Ejemplo en código (Incidente Crítico):

#include <iostream>
#include <array>

int main() {
    // Límite físico fijo de 5 equipos
    std::array<bool, 5> equipos = {true, true, false, true, false};
    std::cout << "Total equipos: " << equipos.size() << std::endl;
    return 0;
}

Explicación: equipos es un std::array con un tamaño inamovible de 5, simulando las computadoras de la biblioteca. Protege de acceder a un "equipo 6" inexistente.

🧁 De la vida cotidiana: Un molde metálico para cupcakes. Si tiene 6 espacios, esa es su capacidad máxima. No puedes estirar el metal para meter un séptimo panecillo.

3. Tipos de Dato Definidos por el Usuario (struct)

Teoría (C++ según Deitel): Permiten agrupar múltiples variables de distintos tipos bajo un mismo nombre. En C++, un struct posee capacidades idénticas a una clase, pudiendo incluir constructores y métodos.

Ejemplo en código (Incidente Crítico):

#include <iostream>
#include <string>

struct SesionPAD {
    int id_usuario;
    std::string tramite;

    SesionPAD(int id, std::string t) : id_usuario(id), tramite(t) {}

    void mostrarEstado() {
        std::cout << "Usuario " << id_usuario << ": " << tramite << "\n";
    }
};

int main() {
    SesionPAD sesion(405, "Acta de Nacimiento");
    sesion.mostrarEstado(); 
    return 0;
}

Explicación: Definimos SesionPAD agrupando atributos. Agregamos un constructor para inicializar los datos y un método mostrarEstado() para encapsular su comportamiento.

🧙‍♀️ De la vida cotidiana: Una ficha de diseño de Hana chan. En lugar de tener sus datos en hojas separadas, el struct concentra todos sus atributos mágicos en una sola plantilla organizada.

4. Estructuras Lineales Estáticas (Colas)

Teoría (C++ según Deitel): Para administrar turnos, las colas siguen el principio FIFO (el primero en entrar es el primero en salir). En C++, se implementa con std::queue.

Ejemplo en código (Incidente Crítico):

#include <iostream>
#include <queue>
#include <string>

int main() {
    std::queue<std::string> cola_atencion;
    
    cola_atencion.push("Usuario Estudiante"); 
    cola_atencion.push("Usuario Trámite INE"); 

    std::cout << "Turno: " << cola_atencion.front() << std::endl;
    cola_atencion.pop(); // FIFO
    
    return 0;
}

Explicación: .push() encola a los usuarios en el orden de llegada. .front() indica quién está adelante, y .pop() desencola al primero respetando el principio FIFO.

☕ De la vida cotidiana: La fila de una cafetería (FIFO). El primer auto que llega al autoservicio es el primero en recibir su pedido. (En una Pila LIFO, sería como una torre de hot cakes).

5. Persistencia de Datos

Teoría (C++ según Deitel): Es la capacidad de almacenar información permanentemente en el disco físico. C++ maneja esto a través de flujos de objetos con la biblioteca <fstream>.

RAM
HDD

Ejemplo en código (Incidente Crítico):

#include <iostream>
#include <fstream>

int main() {
    std::ofstream bitacora("bitacora_PAD.txt");
    
    if (bitacora.is_open()) {
        bitacora << "09:00 AM - Se abre el módulo PAD-Bienestar.\n";
        bitacora.close(); 
        std::cout << "Guardado en disco.\n";
    }
    return 0;
}

Explicación: std::ofstream abre un flujo de escritura hacia el disco duro. Tras inyectar los datos, invocamos .close() para asegurar que la información no se corrompa.

💾 De la vida cotidiana: Tras horas redactando tus rúbricas, la información vive en la RAM (volátil). La persistencia ocurre al hacer clic en "Guardar", transfiriéndolas al disco duro de forma permanente.
